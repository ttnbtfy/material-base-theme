# Changelog

All notable changes to this project will be documented in this file.

## [1.0.11] - 2026-10-20
### Fixed
- README: removed Marketplace version/installs badges that showed "retired badge"
- README: all screenshots re-captured larger and easier to read (UI overview + JSX, TSX, HTML, SCSS, PHP, Java)

## [1.0.10] - 2026-10-20
### Changed
- License is now MIT (free to use, modify and share)
- New 256×256 icon
- README: full UI screenshot, palette, install steps for VSCodium, recommended settings
- Marketplace metadata: description, keywords, banner color, homepage and issues links

## [1.0.9] - 2026-10-19
### Fixed
- Status bar no longer turns purple when no folder is open
- Status bar no longer turns orange while debugging (a thin amber top border is shown instead)
- Visible keyboard focus outline in lists (Explorer, etc.)
- Inactive title bar and sidebar section headers now match the theme

### Added
- Editor gutter colors for added / modified / deleted lines
- Tab border color
- Colors for widgets, hover, suggest, peek view, inputs, dropdowns, quick input, menus, notifications, scrollbars and badges
- Highlighted remote indicator

### Removed
- ~440 unused `col_*` / `none` token rules left over from a tmTheme conversion

## [1.0.0] - 2025-04-23
### Added
- Initial release of Material Base Theme
- Updated README with preview images
- Improved icon display on marketplace
